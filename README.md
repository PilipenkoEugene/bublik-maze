# Бублики в лабиринте

Детская веб-игра: кот ходит по лабиринтам, собирает бублики, ищет ключи и выход,
а на собранные бублики покупает наряды. Без зависимостей: один HTML-файл,
картинка кота, звуки и музыка встроены (звук синтезируется в браузере).

## Что есть в игре

- **18 уровней в 3 мирах** (Пекарня, Парк, Зима): у каждого мира свои цвета, стены,
  частицы в воздухе (искорки, листья, снег) и своя мелодия.
- **Карта уровней** со звёздами. Следующий уровень открывается после прохождения
  предыдущего. Прогресс сохраняется в браузере (`localStorage`).
- **Предметы на поле:** бублики, золотой бублик (+5 в копилку), ключ (без него
  дверь закрыта), мышки-вредины (кот пугается и отскакивает), туман (рассеивается
  вокруг кота).
- **Гардероб:** 7 вещей (цветочек, шарик, бантик, очки-сердечки, корона, плащ,
  звёздочки) покупаются за собранные бублики. Одновременно носится по одной вещи
  на голову, на лицо и «дополнительная» (шарик или плащ).
- **Отклик на действия:** бублик улетает в счётчик, всплывают похвалы, за 3 бублика
  подряд — «Супер!» с конфетти, кот подпрыгивает с разворотом, пугается, потеет
  у стены, мяукает и подсказывает облачком, если долго стоит.
- **Анкета перед игрой:** имя и дата рождения ребёнка, имя, телефон и e-mail родителя,
  согласие на обработку персональных данных. Анкета отправляется на адрес-приёмник
  (см. ниже), без неё игра не начинается.
- **Подарок после 5-го уровня:** экран с именем ребёнка и личным кодом подарка
  («ДВ-4110»). Ребёнок показывает его на стойке, сотрудник удерживает кнопку
  «Подарок выдан» 2 секунды — выдача фиксируется и отправляется в таблицу.
  Пока подарок не выдан, на карте уровней висит кнопка «Твой подарок ждёт!».
- **Общий планшет:** кнопка «Новый игрок» (на стартовом экране, на карте и после
  выдачи подарка) сбрасывает прогресс и анкету для следующего ребёнка.
- **Подсказки** для новых механик при первом запуске уровня и кнопка 💡,
  которая показывает путь (к ключу, если дверь закрыта).

## Структура

- `src/config.js` — **всё, что удобно менять**: адрес приёмника анкет, ссылка на политику,
  тексты и уровень подарка, уровни, миры (цвета, музыка), вещи гардероба и цены
- `src/net.js` — отправка анкет и событий (с очередью на случай, если нет сети)
- `src/audio.js` — звуки и музыка
- `src/draw.js` — рисование бубликов, ключа, мышки, вещей
- `src/game.js` — логика игры, экраны, управление
- `src/style.css`, `src/markup.html` — оформление и разметка
- `assets/cat.webp` — спрайт кота (вырезан из `cat_original.jpeg`)
- `build.mjs` — сборка: `node build.mjs`
- `dist/index.html` — готовая отдельная страница
- `dist/tilda-block.html` — фрагмент для Тильды

## Куда уходят анкеты

Игра отправляет POST-запрос с JSON на адрес `FORM.submitUrl` из `src/config.js`.
**Пока адрес пустой, работает демо-режим:** игра работает, данные только пишутся
в консоль браузера. Перед запуском для детей адрес обязательно нужно задать.

События (поле `event`):

| event | когда | поля |
|---|---|---|
| `registration` | заполнена анкета | `player_id`, `gift_code`, `child_name`, `child_birthdate` (ДД.ММ.ГГГГ), `child_age` (полных лет), `parent_name`, `parent_phone`, `parent_email`, `consent_pd`, `consent_ads` |
| `gift_earned` | пройден 5-й уровень | `player_id`, `gift_code`, `child_name`, `parent_phone`, `level` |
| `gift_claimed` | сотрудник отметил выдачу | `player_id`, `gift_code`, `child_name`, `parent_phone` |

Во всех событиях есть также `created_at`, `page` и `utm_*` метки из адреса страницы.
Если сети нет, события копятся в браузере и отправляются при следующем открытии игры.

### Готовый вариант: Google Таблица (бесплатно, без сервера)

1. Создайте Google Таблицу → «Расширения» → «Apps Script».
2. Замените код на этот и сохраните:

```js
function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.waitLock(10000);
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
    var headers = sheet.getLastColumn() ? sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0] : [];
    Object.keys(data).forEach(function (k) {
      if (headers.indexOf(k) < 0) { headers.push(k); sheet.getRange(1, headers.length).setValue(k); }
    });
    sheet.appendRow(headers.map(function (h) { return data[h] !== undefined ? data[h] : ''; }));
  } finally {
    lock.releaseLock();
  }
  return ContentService.createTextOutput('ok');
}
```

3. «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение»,
   «Запуск от имени»: я, «У кого есть доступ»: все → «Развернуть», разрешить доступ.
4. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec` и соберите игру:

```bash
SUBMIT_URL="https://script.google.com/macros/s/…/exec" node build.mjs
```

   (или впишите адрес в `FORM.submitUrl` в `src/config.js` и запустите `node build.mjs`).

Столбцы в таблице создаются сами по названиям полей.

### Про Яндекс Формы

Напрямую отправлять ответы из своей формы в Яндекс Формы не получится без сервера:
для записи ответов через API нужен секретный токен, а его нельзя хранить в коде
страницы. Варианты: Google Таблица (выше), Яндекс Cloud Functions как посредник,
или сервисы Make / Zapier / Albato — у них есть приём вебхуков и запись в Яндекс
Таблицы, amoCRM, Битрикс24 и т.п. Игре всё равно: ей нужен только адрес для POST.

### Персональные данные

Анкета собирает данные детей и родителей, поэтому по 152-ФЗ нужны согласие
родителя (галочка в анкете обязательна) и политика обработки ПД — укажите ссылку
в `FORM.privacyUrl`, она появится рядом с галочкой. Текст согласия стоит
согласовать с юристом. Учтите, что Google-серверы находятся за рубежом
(требования о локализации данных граждан РФ) — для боевого запуска надёжнее
приёмник на российских серверах.

## Как вставить в Тильду

**Вариант 1 — прямо в страницу.** Добавить блок «Другое → T123 HTML-код», вставить
целиком содержимое `dist/tilda-block.html`, опубликовать. В редакторе Тильды
код не исполняется — проверять на опубликованной странице или в предпросмотре.

**Вариант 2 — через iframe.** Залить `dist/index.html` на любой статический хостинг
(GitHub Pages, Netlify, Яндекс Object Storage) и в блок T123 вставить:

```html
<iframe src="https://ВАШ-АДРЕС/index.html" style="width:100%;height:760px;border:0" allow="autoplay"></iframe>
```

Когда игра прокручена за пределы экрана, она ставится на паузу и музыка
замолкает — страница не тормозит.

## Управление

- стрелки / WASD (после клика по игре, чтобы не мешать прокрутке страницы), Esc — карта
- нажатие на клетку — кот сам идёт туда; свайп — бежит до развилки
- на телефонах и планшетах — экранные кнопки

## События для аналитики

При прохождении уровня на элементе игры всплывает событие `bublikmaze:win`:

```js
document.addEventListener('bublikmaze:win', function (e) {
  // e.detail = { level, bagels, total, stars, gold }
  // например: ym(XXXX, 'reachGoal', 'maze_level_' + e.detail.level);
});
```

Также: `bublikmaze:register` (анкета заполнена, `detail.age`) и `bublikmaze:gift`
(подарок выдан, `detail.code`). Личные данные в эти события не попадают.

## Сброс прогресса

Кнопка «Новый игрок» в игре или в консоли браузера: `localStorage.removeItem('bublikMaze.v1')`.
